# DevOps-Lab04

## คำอธิบายโปรเจกต์

เว็บไซต์ต้นแบบสำหรับแจ้งปัญหาและขอความช่วยเหลือด้าน IT Support ในที่เดียว ผู้ใช้สามารถดูประเภทปัญหาที่ทีม IT รองรับ เช่น คอมพิวเตอร์และอุปกรณ์ เครือข่าย โปรแกรมและบัญชีผู้ใช้ รวมถึงดูขั้นตอนการรับเรื่องและการติดตามงาน

หน้าเว็บมีแบบฟอร์มสำหรับกรอกข้อมูลผู้แจ้ง ช่องทางติดต่อ ประเภทและรายละเอียดของปัญหา พร้อมตรวจสอบข้อมูลเบื้องต้นก่อนส่ง แบบฟอร์มนี้เป็นเพียงตัวอย่างสำหรับสาธิตการใช้งาน ยังไม่ได้เชื่อมต่อฐานข้อมูลหรือระบบรับแจ้งจริง
